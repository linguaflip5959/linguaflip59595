# ТЗ LinguaFlip — новая система изучения глаголов

## 1. Цель

Заменить существующую компактную таблицу спряжений на мобильную систему, которая:

1. хорошо читается на телефоне;
2. не требует постоянного увеличения экрана;
3. заставляет пользователя **вспоминать**, а не просто смотреть;
4. показывает связь между формой глагола и её употреблением;
5. сохраняет возможность быстро посмотреть грамматическую структуру;
6. не превращает приложение в перегруженный учебник.

Главный принцип:

> **Таблица — справочник. Тренировка — обучение.**

---

# 2. Новая навигация

Существующий раздел:

> **Карточки | Таблица**

заменить на:

> **Карточки | Глаголы**

При открытии **Глаголы** пользователь попадает в список изучаемых глаголов.

Например:

```text
Глаголы

┌─────────────────────────┐
│ GO                      │
│ идти                    │
│ ███████░░░  70%         │
└─────────────────────────┘

┌─────────────────────────┐
│ HAVE                    │
│ иметь                   │
│ █████░░░░░  50%         │
└─────────────────────────┘

┌─────────────────────────┐
│ MAKE                    │
│ делать                  │
│ ██░░░░░░░░  20%         │
└─────────────────────────┘
```

Нажатие на глагол открывает **экран глагола**.

---

# 3. Экран глагола

Например:

# GO

**идти**

Под заголовком четыре режима:

```text
[ Учить ] [ Тренировать ] [ Карта ] [ Формы ]
```

При этом:

* **Учить** = вариант №1;
* **Тренировать** = вариант №4;
* **Карта** = вариант №3;
* **Формы** = компактный справочник.

Таким образом, пользователь не видит четыре совершенно разных системы.

---

# 4. Режим №1 — «Карточка глагола»

Это **основной режим знакомства с новым глаголом**.

## Экран

```text
┌───────────────────────────┐
│                           │
│            GO             │
│           идти            │
│                           │
│      go — went — gone     │
│                           │
│       🔊 произношение      │
│                           │
└───────────────────────────┘

        [ Начать изучение ]
```

Пользователь нажимает «Начать изучение».

---

## Шаг 1 — Present

```text
GO

Обычно / регулярно

Present Simple

I ___ to work every day.

[ показать ответ ]
```

После нажатия:

```text
GO

I GO to work every day.

✓ go
```

---

## Шаг 2 — Past

```text
GO

Вчера / раньше

Past Simple

I ___ to work yesterday.

[ показать ответ ]
```

Ответ:

> **went**

---

## Шаг 3 — Perfect

```text
GO

Уже произошло

Present Perfect

I have ___ home.

[ показать ответ ]
```

Ответ:

> **gone**

---

## Шаг 4 — Continuous

```text
GO

Прямо сейчас

Present Continuous

I am ___ home.

[ показать ответ ]
```

Ответ:

> **going**

---

## Шаг 5 — Future

```text
GO

Будущее

Future Simple

I will ___ tomorrow.

[ показать ответ ]
```

Ответ:

> **go**

---

# 5. Важное правило режима №1

На этапе первого знакомства **не требовать от пользователя ввода**.

Сначала:

> увидеть → услышать → понять → повторить.

Только после этого переходить к активному вспоминанию.

Это особенно важно для новичков.

---

# 6. Режим №4 — «Ситуации»

Это **главный тренировочный режим**.

Здесь пользователь уже ничего не получает бесплатно.

Например:

```text
GO

Вчера

I ___ to London yesterday.

             [ ______ ]

           [ ПРОВЕРИТЬ ]
```

Пользователь вводит:

> went

Нажимает:

**Проверить**

---

## Правильный ответ

```text
✓ Правильно!

I WENT to London yesterday.

Past Simple
```

Кнопка:

> **Дальше →**

---

## Неправильный ответ

Например:

> goed

Получаем:

```text
✗ Не совсем.

Правильно:

WENT

I WENT to London yesterday.

Запомни:
GO → WENT
```

Далее:

> **Повторить**

или

> **Дальше**

---

# 7. Типы заданий

На первом этапе достаточно **трёх типов**.

### Тип A — ввод

> I ___ yesterday.

Пользователь пишет:

> went

---

### Тип B — выбор

```text
I ___ yesterday.

○ go
○ went
○ gone
○ going
```

---

### Тип C — распознавание

```text
I have GONE home.

Что означает GONE?

○ идти
○ пошёл / ушёл
○ идти прямо сейчас
```

Это позволит избежать ситуации, когда пользователь просто запоминает написание.

---

# 8. Режим №3 — «Лестница времён»

Это **визуальный экран**, а не основной тренировочный режим.

Он нужен, чтобы человек увидел структуру.

На телефоне:

```text
             GO
             │
             ▼

       ┌─────────────┐
       │   Обычно    │
       │     GO      │
       │ Present     │
       └─────────────┘
             │
             ▼
       ┌─────────────┐
       │    Вчера    │
       │    WENT     │
       │ Past        │
       └─────────────┘
             │
             ▼
       ┌─────────────┐
       │    Уже      │
       │    GONE     │
       │ Perfect     │
       └─────────────┘
             │
             ▼
       ┌─────────────┐
       │   Сейчас    │
       │   GOING     │
       │ Continuous  │
       └─────────────┘
```

Карточки должны быть **крупными**.

Никаких 10–12 колонок.

---

# 9. Нажатие на элемент лестницы

Например пользователь нажимает:

> WENT

Открывается:

```text
WENT

Past Simple

GO → WENT

I WENT to London yesterday.

🔊
```

То есть лестница становится интерактивной.

# 10. Режим №5 — «Нейронная карта»

## ⚠️ НЕ ВХОДИТ В ПЕРВУЮ ВЕРСИЮ

Это отдельная будущая функция.

Не закладываем её в основной MVP.

Концепция:

```text
                  GO
               /  |  \
              /   |   \
           WENT  GONE GOING
             \    |    /
              \   |   /
               CONTEXT
```

Каждая форма является отдельным узлом.

Нажатие на узел:

> форма → время → значение → пример → произношение.

В будущем карта может показывать связи между:

* формами;
* временами;
* значениями;
* примерами;
* неправильными формами;
* частыми конструкциями.

### Почему откладываем

Потому что это **визуально сложная функция**, которая не является необходимой для проверки основной гипотезы LinguaFlip.

Сначала проверяем:

> **удобнее ли человеку учить глаголы через карточку + ситуации + лестницу?**

Если да — делаем карту.

# 11. Экран «Формы»

Я бы всё-таки оставил компактный справочник.

Но вместо таблицы Петрова:

```text
GO
│
├── go
├── went
├── gone
└── going
```

Например:

```text
GO
идти

┌─────────────────────┐
│ Base                │
│ GO                  │
│ идти                │
└─────────────────────┘

┌─────────────────────┐
│ Past                │
│ WENT                │
│ пошёл / пошла       │
└─────────────────────┘

┌─────────────────────┐
│ Participle          │
│ GONE                │
└─────────────────────┘

┌─────────────────────┐
│ -ing                │
│ GOING               │
└─────────────────────┘
```

Это заменяет старую таблицу как **справочную информацию**.

# 12. Структура данных

Для каждого глагола желательно хранить:

```text
verb
translation

base_form
past_form
participle_form
ing_form

pronunciation_base
pronunciation_past
pronunciation_participle

present_examples[]
past_examples[]
perfect_examples[]
continuous_examples[]
future_examples[]

difficulty
progress
last_review
next_review

correct_answers
wrong_answers
```

Например:

```text
verb: GO
translation: идти

base_form: go
past_form: went
participle_form: gone
ing_form: going
```

---

# 13. Система прогресса

Каждая форма должна изучаться **отдельно**.

Например:

```text
GO

go      ██████████ 100%
went    ██████░░░░ 60%
gone    ████░░░░░░ 40%
going   ████████░░ 80%
```

Общий прогресс:

> **70%**

Это намного информативнее, чем:

> «Глагол GO изучен».

Потому что пользователь может прекрасно знать **go**, но постоянно путать **went/gone**.

---

# 14. Повторение

После каждого ответа записываем:

```text
correct / incorrect
form
time
date
```

Например:

```text
GO → WENT
✓
```

или:

```text
GO → GONE
✗
```

На следующей тренировке система должна чаще показывать проблемные формы.

**На первом этапе не нужно изобретать собственный сложный алгоритм.**

Можно использовать уже существующий механизм интервального повторения LinguaFlip и просто передавать ему:

> `verb_id + form_id`

То есть карточка:

> GO

и карточка:

> GO → WENT

могут иметь **разный уровень запоминания**.
